Notes on all three

  • Same skeleton. Header → hero → primary actions → sector destinations → member restaurants → JRA in numbers → news → membership → newsletter → footer. Nothing is dropped in any direction; each expresses the sections differently.
  • Real data. Restaurants, cuisines, governorates and features come from resutaurants.xlsx via tools/extract.py. Picture 1 in the export is always the venue logo; Picture 2 is the actual photograph, which is what these pages use.
  • Palettes come from the logo, not from taste. The artwork uses exactly two colours — #0053A0 for the ellipse mark and #6C6D70 for all type. Every surface, rule and accent in all three directions is a tonal step on those two. Direction C adds a muted amber and green, used only to distinguish a legislative alert from an opportunity; they are status indicators, not brand colours.
  • The logo needs an official reversed version. The supplied lockup is blue-and-grey on white and disappears on dark footers, so the knockout used here was generated by forcing the artwork white. Ask the association for a sanctioned reversed lockup before production.
  • Photos are hotlinked from jra.jo for mockup purposes. They must be self-hosted and resized before production.
  • Arabic is wired but not translated. Every string carries a translation key and all CSS uses logical properties, so the عربي toggle already flips the whole layout to RTL. Only the dictionary is empty.
  • Accessibility. Visible focus rings, 44px touch targets, keyboard-reachable tile panels, prefers-reduced-motion honoured, no horizontal scroll at 375px.
  • Not built yet. Backend, CMS, member login, and every page other than home — this is a look-and-feel decision, not the build.
